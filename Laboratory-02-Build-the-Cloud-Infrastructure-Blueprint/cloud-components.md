# Cloud Infrastructure Components

## 1. Compute Resources

### Purpose

Compute resources provide the processing power required to run applications, services, and workloads. They include resources such as CPUs and processor cores.

### Importance in Cloud Computing

Compute resources are important because cloud applications need processing power to execute tasks. Cloud providers allow organizations to increase or decrease computing resources depending on their workload requirements.

### Relation to KillerCoda

The KillerCoda Linux environment provides CPU resources that can be investigated using commands such as `lscpu` and `nproc`. These commands display information about the processor and number of available CPU cores.

---

## 2. Storage Resources

### Purpose

Storage resources provide persistent space for operating system files, applications, configuration files, and data.

### Importance in Cloud Computing

Storage is important because applications and users need a reliable place to save information. Cloud platforms provide scalable storage that can accommodate increasing amounts of data.

### Relation to KillerCoda

The Linux environment contains disk storage that can be examined using commands such as `lsblk` and `df -h`. These commands show available disks, partitions, and filesystem usage.

---

## 3. Networking Resources

### Purpose

Networking resources allow computers, servers, applications, and users to communicate with one another.

### Importance in Cloud Computing

Networking is essential because cloud services depend on communication between users, servers, databases, storage systems, and the Internet.

### Relation to KillerCoda

The KillerCoda Linux environment has network interfaces and an IP address. Commands such as `hostname -I` and `ip addr` can be used to identify the server's network information.

---

## 4. Operating System

### Purpose

The operating system manages the computer's hardware and provides an environment where applications and services can run.

### Importance in Cloud Computing

The operating system is important because cloud servers need software that manages CPU, memory, storage, networking, processes, and other resources.

### Relation to KillerCoda

KillerCoda provides a Linux-based environment. Linux manages the resources of the cloud server and provides the terminal and tools used to investigate the infrastructure.
