# Automation Research

## 1. Bash Script

A Bash script is a text file containing Linux commands that can be executed together to automate tasks. The `#!/bin/bash` line, called the shebang, tells the system to use the Bash interpreter to execute the script.

## 2. Variables

Variables store values, such as folder paths, filenames, or timestamps, so they can be reused throughout a script. For example, `$BACKUP_DIR` makes it easier to change the backup location in one place instead of editing every command that uses the path.

## 3. Cron Job

A cron job is a scheduled task in Linux that runs commands or scripts automatically at specified times or intervals. It is essential in cloud operations because it can automate recurring tasks such as backups, log cleanup, and system maintenance without requiring someone to run them manually.
