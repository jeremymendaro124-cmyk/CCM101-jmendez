# Microsoft Azure Research

## Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides infrastructure, databases, networking, storage, security, analytics, artificial intelligence, application development, and other cloud services. Azure reached general availability in 2010.

## Global Infrastructure

Azure uses a global infrastructure organized into geographies and regions. Azure geographies contain one or more regions and are designed to address requirements such as data residency, compliance, availability, and geographic proximity.

## Cloud Management Console

The **Azure Portal** is the web-based management interface for Microsoft Azure. It allows administrators and developers to create, configure, monitor, and manage Azure resources from a central interface.

## Four Core Services

1. **Azure Virtual Machines** – Provides scalable virtual machines for Windows and Linux workloads.
2. **Azure Blob Storage** – Provides object storage for unstructured data.
3. **Azure Virtual Network** – Provides private networking for Azure resources.
4. **Microsoft Entra ID** – Provides identity and access management.

Azure Virtual Network can also connect cloud resources with existing on-premises environments using VPN or Azure ExpressRoute.

## Three Advantages

* **Microsoft integration** – Azure works especially well with Windows Server, Microsoft 365, Active Directory, and other Microsoft technologies.
* **Hybrid cloud support** – Organizations can connect on-premises infrastructure with Azure.
* **Enterprise capabilities** – Azure provides extensive security, compliance, identity, database, and management services.

## Typical Enterprise Use Cases

Azure is commonly used for:

* Windows Server migration
* Microsoft 365 and enterprise integration
* Hybrid cloud infrastructure
* Enterprise applications
* Database hosting
* Virtual desktop infrastructure
* Artificial intelligence and analytics
