# Cloud Platform Recommendation Challenge

## Client A – Startup Company

### Recommended Platform: AWS

AWS is recommended because the startup has a limited budget but expects rapid growth. AWS provides scalable infrastructure that allows the company to start with relatively small resources and increase capacity as its application grows. The company can use managed and serverless services to reduce infrastructure management. AWS also provides services suitable for mobile and web application development.

**Possible Services:**

* Amazon EC2
* Amazon S3
* Amazon RDS
* AWS Lambda
* Amazon API Gateway

---

## Client B – University

### Recommended Platform: Microsoft Azure

Azure is the best choice because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft's identity and enterprise ecosystem. The university can use Microsoft Entra ID and Azure networking to connect cloud resources with its existing environment. This can make migration easier and reduce compatibility issues.

**Possible Services:**

* Azure Virtual Machines
* Microsoft Entra ID
* Azure Virtual Network
* Azure Blob Storage
* Azure SQL Database

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

Google Cloud is recommended because the company focuses on Artificial Intelligence and Machine Learning. Google Cloud provides AI and machine-learning infrastructure together with services for data processing and high-performance workloads. Its strong data analytics capabilities can also help researchers process large datasets. GKE can be used when AI workloads need container orchestration.

**Possible Services:**

* Compute Engine
* Vertex AI
* Google Kubernetes Engine
* Cloud Storage
* BigQuery

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended for the global e-commerce company because it has a large worldwide infrastructure and services designed for scalable applications. The company can deploy workloads across multiple regions and Availability Zones for improved availability. Auto Scaling and load balancing can automatically respond to changing customer demand. AWS services can also support databases, object storage, monitoring, and content delivery.

**Possible Services:**

* Amazon EC2
* Amazon S3
* Elastic Load Balancing
* EC2 Auto Scaling
* Amazon RDS
* Amazon CloudFront
