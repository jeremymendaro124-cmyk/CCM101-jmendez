# Mission 3 Reflection

Completing the Multi-Cloud Explorer mission helped me understand how major cloud providers differ while still providing many similar services. Among AWS, Microsoft Azure, and Google Cloud Platform, AWS impressed me the most because of its wide range of services and global infrastructure. AWS provides many solutions for computing, storage, networking, databases, security, analytics, and application development. I also found it useful that AWS can support both small startups and large global organizations.

AWS, Azure, and GCP have many similarities. All three provide virtual machines, object storage, networking, identity and access management, databases, Kubernetes services, and tools for monitoring and application development. They also use a global infrastructure based on regions and data centers or zones. Although the services have different names, they solve many of the same business and technical problems.

Business requirements strongly influence cloud platform selection. For example, a company that already depends heavily on Microsoft products may benefit more from Azure because of its integration with Microsoft technologies. An AI research company may prefer Google Cloud because of its AI, machine learning, and data capabilities. A global company may prioritize availability, scalability, geographic coverage, and the services needed to operate worldwide.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. I need to examine the organization's budget, existing technology, performance requirements, scalability needs, security requirements, and future goals before making a recommendation.

 My GitHub Cloud Computing Portfolio improved because it now contains organized research, comparisons, recommendations, Linux investigation results, screenshots, and reflections. This mission helped me practice both technical cloud knowledge and professional documentation skills. It also showed me how important clear evidence and organized GitHub repositories are when presenting technical work.
