# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

This laboratory activity focuses on investigating a Linux-based cloud environment and understanding the basic components of cloud infrastructure. The activity also involves researching major cloud providers, designing a simple cloud infrastructure architecture, documenting Linux commands, and updating a GitHub portfolio.

## Objectives

* Investigate the Linux environment provided by KillerCoda.
* Identify important cloud infrastructure components.
* Understand the equivalent services offered by AWS, Microsoft Azure, and Google Cloud Platform.
* Design a simple cloud infrastructure diagram.
* Practice technical documentation using Markdown.
* Use GitHub to organize and maintain a cloud computing portfolio.

## Cloud Infrastructure Components

The main infrastructure components investigated in this laboratory are:

* **Compute Resources** – Provides processing power for running applications and workloads.
* **Storage Resources** – Stores operating system files, applications, and user data.
* **Networking Resources** – Allows systems and services to communicate with each other and with the Internet.
* **Operating System** – Manages hardware resources and provides an environment for applications and services.

## Challenges Encountered

One challenge encountered during this laboratory was understanding the information returned by different Linux commands. Some commands provide detailed technical information that can initially be difficult to interpret. Another challenge was comparing equivalent services between AWS, Azure, and Google Cloud because each provider uses different service names.

Despite these challenges, the activity helped improve my ability to investigate a cloud environment, understand infrastructure resources, and document technical information clearly.
