# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means that every user or application should receive only the permissions needed to perform its assigned tasks. In cloud computing, this helps protect accounts and resources because users cannot access sensitive information or perform administrative actions beyond their responsibilities.

## 2. Attack Surface

The attack surface refers to all the possible entry points an attacker could use to access or compromise a virtual machine. These entry points may include open network ports, running services, outdated software, and accounts with weak security. Reducing unnecessary services and access points makes the virtual machine more secure.

## 3. Default Deny Policy

A Default Deny Policy blocks incoming network traffic unless a specific firewall rule permits it. This is safer than blocking individual hackers because unknown or unauthorized connections are rejected automatically, even if their sources have not been identified. Only required services are allowed to receive traffic.
