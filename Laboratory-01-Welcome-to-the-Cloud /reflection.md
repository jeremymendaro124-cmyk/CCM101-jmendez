## Reflection

This activity helped me understand how to create and manage a user account using Bash commands in Linux. I learned how to create a new user with a home directory and Bash shell, set a password, and give the user sudo privileges. I also learned how to switch or log in to the newly created user account.

Through this activity, I became more familiar with basic Linux commands such as useradd, passwd, usermod, su, whoami, pwd, and hostname. I learned that these commands are important for managing users and checking system information.

Overall, this activity improved my confidence in using the Linux terminal. It also helped me understand the importance of user accounts, permissions, and system administration in Linux. I realized that learning Bash commands is useful for managing computers and developing my skills in Information Technology.
