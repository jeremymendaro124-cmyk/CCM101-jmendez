# Google Cloud Platform Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is Google's cloud computing platform. It provides computing, storage, networking, databases, analytics, artificial intelligence, machine learning, and container services.

## Global Infrastructure

Google Cloud provides a global infrastructure distributed across regions and zones. As of August 31, 2026, Google Cloud lists 43 global regions and 130 zones across six continents. Its infrastructure also uses Google's global network to provide high-performance connectivity.

## Cloud Management Console

The **Google Cloud Console** is a web-based management interface used to create, configure, monitor, and manage Google Cloud resources and services.

## Four Core Services

1. **Compute Engine** – Provides configurable virtual machines.
2. **Cloud Storage** – Provides scalable object storage.
3. **Google Kubernetes Engine (GKE)** – Provides managed Kubernetes clusters.
4. **Cloud IAM** – Controls access and permissions for Google Cloud resources.

Google Cloud also provides a global Virtual Private Cloud for networking Compute Engine, GKE, and serverless workloads.

## Three Advantages

* **Artificial Intelligence and Machine Learning** – Google has strong AI and data analytics capabilities.
* **Kubernetes expertise** – Google Cloud provides Google Kubernetes Engine for managed Kubernetes deployments.
* **Global network** – Google's global network provides high-performance connectivity for applications operating worldwide.

## Typical Enterprise Use Cases

Google Cloud is commonly used for:

* Artificial intelligence and machine learning
* Big data analytics
* Kubernetes applications
* Web applications
* Data warehousing
* Global applications
* Modern cloud-native systems
